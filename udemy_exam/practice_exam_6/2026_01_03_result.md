```python
  ↓
出力
```

- INFO  → **Handler(WARNING) で除外**
- WARNING → 出力
- ERROR   → 出力

- Python の Logger は 名前の階層構造を持つ

```python
root
```

**propagate の役割**
- 子 Logger → 親 Logger に**ログを伝播するかを制御**
- `logger.propagate = False  # 親には伝わらない`
- デフォルトは True
- Handler が複数ある場合、二重出力の原因になる

**解説**
`p = list(itertools.product(nums, repeat=2))[:4]`
- 直積（デカルト積） を生成する関数
- `itertools.product(A, B)`とすることで、A の各要素 × B の各要素
- numsの**重複ありの全組み合わせのリストを作成**

- `repeat=2`とすることで、**同じ iterableを何回繰り返して直積（デカルト積）を取るか指定**
- 2のため、`itertools.product(nums, nums)`と同じ意味になる

`[:4]`
- 先頭4個だけを取り出す

`pe = list(itertools.permutations(nums, 2))`
- nums の中から 異なる2要素を選び、**重複なし・順序あり**のリストを作成
- 結果：`[(3, 5), (3, 2), (5, 3), (5, 2), (2, 3), (2, 5)]`

`c = list(itertools.combinations(nums, 2))`
- nums から 異なる2要素を選び、**重複なし・順序なし**のリストを作成
- (3, 5) と (5, 3) は同じ組として 扱う
- 結果：`[(3, 5), (3, 2), (5, 2)]`

`cr = list(itertools.combinations_with_replacement(nums, 2))`
