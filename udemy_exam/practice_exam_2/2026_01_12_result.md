### 次のうち、「メールアドレスのような形式（例：user@example.com）」 を簡単に判定するための正規表現として最も適しているものはどれか？

```python
1. r"\w+@\w+\.\w+"
2. r"\d+@\d+\.\d+"
3. \w+@\w+\.\w+
4. r"email"
```

**回答**
`r"\d+@\d+\.\d+"`

**正解**
`r"\w+@\w+\.\w+"`

**解説**
- 正規表現（Regex）は文字列のパターンを表現するための方法です。
- メールアドレスの簡単な形式は ユーザー名@ドメイン.トップレベルドメイン です。

`r"\w+@\w+\.\w+"`

- `r"～"`
  - raw文字列　これがあることで正しく正規表現となる

- `\w`
  - **英数字**とアンダースコア (`[a-zA-Z0-9_]`) を意味する

- `+` 
  - 1文字以上の繰り返し

- `@`
  - 文字通りの「@」

- `\.`
  - ピリオド（. は正規表現で任意の1文字を意味するので、エスケープが必要）

`"\w+@\w+\.\w+"` と書くと、Python が` \ `を特別な意味（エスケープ文字）として処理しようとする ため、意図した正規表現にならない 可能性があります。

### 標準出力ではなく標準エラー出力に文字列を表示する正しい方法はどれ？

```python
1. sys.print("Error occurred")
2. sys.stderr("Error occurred")
3. print("Error occurred")
4. print("Error occurred", file=sys.stderr)
```

**回答**
`sys.stderr("Error occurred")`

**正解**
`print("Error occurred", file=sys.stderr)`

**解説**
`print("Error occurred", file=sys.stderr)`

- このコードは 「`Error occurred`」という文字列を標**準エラー出力**（stderr）に書き込む」 という意味です。

`stdout`
- 正式名称: standard output
- 意味: 標準出力


`stderr`

- 正式名称: standard error
- 意味: 標準エラー出力

### ディレクトリを再帰的に削除する関数はどれ？

```python
1. os.remove()
2. shutil.rmtree()
3. shutil.removedirs()
4. os.rmdir()
```

**回答**
`os.rmdir()`

**正解**
`shutil.rmtree()`

**解説**
`os.remove()`
- ファイルを削除する関数
- ディレクトリは削除できない



`os.rmdir()`
- **空のディレクトリを削除**する
- 中身があるディレクトリは削除できない

`shutil.rmtree()`
- **ディレクトリとその中の全てのファイル・サブディレクトリを再帰的に削除**する
- 大量のファイルが入ったフォルダをまとめて削除したいときに便利



`shutil.removedirs()`
- 指定したディレクトリと その**親ディレクトリを空の場合にまとめて削除**
- 中身があるディレクトリは削除できない
